# Панель управления RouteWolf

В исходном архиве RouteWolf запустите `sh install.sh` и выберите **Установить для управления через LuCI**, либо передайте `--luci`. Установщик подготовит базовые службы RouteWolf и добавит **Службы → RouteWolf**. Настройку туннеля можно выполнить после этого в браузере. Для действующей установки используйте команду из [раздела обновления](../README.md#переход-на-v60).

- **Обзор** показывает состояние туннеля, WAN и watchdog. Кнопка паузы переводит новые потоки RouteWolf на WAN. Возобновление запускает прежний туннель при необходимости и проверяет восстановленный маршрут.
- **Профили** поддерживают AmneziaWG и WireGuard с одним IPv4-пиром и AllowedIPs 0.0.0.0/0, OpenVPN с сертификатами внутри клиентского файла, подписки и ссылки sing-box и VLESS · Xray, а также ключи Outline. Для HTTPS-подписки откройте **Серверы** рядом с профилем, чтобы выбрать предпочитаемый узел. При его отказе RouteWolf использует другой доступный узел и возвращается к выбранному после восстановления. Перед активацией панель показывает недостающие компоненты и устанавливает их после подтверждения.
- **Списки** открывает библиотеку из уже загруженных списков проекта. Можно искать записи, выбирать страницу или добавлять все результаты текущего фильтра. Домены сгруппированы по сервисам. В группу Telegram входят совпавшие с официальным списком диапазоны, остальные IP доступны в общей библиотеке. Скопированные записи сразу видны в редакторе. «Применить списки» сохраняет их и обновляет маршрутизацию. В выборочном режиме исключения идут через WAN, свои записи имеют приоритет над исключениями. Галочка «Использовать списки проекта» при снятии оставляет только свои записи. Ночное обновление в 02:00 можно отключить независимо от ручного обновления библиотеки.
- **Управление** включает запуск службы списков при загрузке, переключатель автообновления кода, перехват DNS, запуск обновления из стабильного выпуска, проверку и восстановление правил. Управление DCO доступно при активном OpenVPN.

В **Управление → Удалить компоненты** можно выбрать установленные группы Xray (включая VLESS по WebSocket), sing-box (включая Outline), OpenVPN, AmneziaWG и WireGuard. Когда удалён последний профиль компонента, RouteWolf предлагает очистить его пакеты сразу. Компоненты, нужные сохранённым профилям и активным интерфейсам, защищены. Удаление пакетов освобождает место в хранилище. Оперативную память занимает работающий процесс.

После первоначальной установки RouteWolf для LuCI сеть перезапускается автоматически. При активации профиля LuCI тоже перезапустит сеть, если OpenWrt ещё не загрузил установленный протокол WireGuard или AmneziaWG. После этого проверка туннеля продолжится.

В **Профилях** назначьте основной профиль и, при необходимости,
резерв из других сохранённых профилей. Для основного профиля sing-box
сначала проверяются все серверы подписки. Резервный интерфейс стартует
при отказе основного, а IPv4 направляется через него после проверки HTTPS.
При недоступности обоих туннелей работает маршрут через WAN. После возврата
основного профиля резерв останавливается. Запуск при загрузке выбран по умолчанию
для новых профилей. Чтобы применить правки к конфигурации резерва, назначьте
обновлённый профиль заново.

В поле **DNS профиля** можно задать до четырёх IPv4/IPv6-адресов, доступных
с роутера. Они добавляются к резолверам dnsmasq при работе профиля. Резолверы
провайдера сохраняются. Пустое поле использует обычную конфигурацию DNS.

Профиль **VLESS · Xray** запускает Xray-core через собственную службу RouteWolf.
Доступны `vless://` и HTTPS-подписки со списком VLESS-ссылок или конфигурациями
Xray JSON, включая XHTTP.
Конфигурация проверяется Xray перед запуском. Правила переведут клиентский
трафик через туннель после успешной HTTPS-проверки. Профиль можно назначить
основным или резервным.

В **Списках → Импорт GeoIP / GeoSite** доступны категории вида
`geoip:telegram` и `geosite:youtube`. Поддерживаемые домены и CIDR попадают в
редактор собственных списков. После применения они работают для всех
протоколов в режиме «Выборочно по спискам RouteWolf». Полные доменные имена
включают поддомены. Сложные правила и IPv6 при отключённой IPv6-маршрутизации
пропускаются.

Подписки и загрузка компонентов используют DNS, настроенный на роутере. Только явное изменение настройки перехвата DNS в панели меняет режим перехвата.

Профили содержат ключи и ссылки. Файл `/etc/config/routewolf_ui` доступен root и пользователям с доступом к конфигурации этого приложения.
