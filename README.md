# RouteWolf

Управление VPN-туннелями и маршрутизацией OpenWrt. Панель находится в **Службы → RouteWolf**. Поддерживаются WireGuard, AmneziaWG, OpenVPN, Outline, sing-box и VLESS через Xray.

## Установка

```sh
/bin/uclient-fetch -O - https://raw.githubusercontent.com/dagmagnat/RouteWolf/main/install.sh | sh
```

По умолчанию устанавливается версия с LuCI. Для консольной настройки добавьте в конец команды `-s -- --console`. Если архив уже скачан и распакован, выполните `sh ./install.sh` из его папки.

## Обновление

Кнопка **Управление → Обновить проект** и команда `rw update` обновляют проект вместе с LuCI.

### Переход на v60

На старой консольной установке или если прежняя кнопка не обновляет панель, один раз запустите эту команду. Она сохраняет настройки и добавляет актуальную LuCI.

```sh
/bin/uclient-fetch -O - https://raw.githubusercontent.com/dagmagnat/RouteWolf/main/update.sh | sh
```

Для обновления старой консольной установки без добавления панели используйте `sh -s -- --console` вместо `sh` в конце команды.

## Существующие туннели

Откройте **Профили → Существующие интерфейсы OpenWrt**. RouteWolf покажет найденные туннели. Кнопка **Добавить в профили** передаст выбранный интерфейс в управление RouteWolf. Для нового профиля используется режим всего трафика, для уже настроенного в RouteWolf сохраняется текущий режим.

## Удаление

В актуальной установке выполните `rw uninstall`. Для старых версий используйте ту же полную очистку через GitHub.

```sh
/bin/uclient-fetch -O - https://raw.githubusercontent.com/dagmagnat/RouteWolf/main/uninstall.sh | sh
```

Введите `DELETE`. Скрипт удалит панель, настройки, туннели и маршруты проекта. Затем можно отдельно подтвердить удаление VPN-пакетов, установленных RouteWolf. После этого обычная команда установки запустит новую настройку.
